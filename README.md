# ConfereAí — site estático (Projeto Integrador Senac)

## Publicar grátis na Cloudflare Pages
**Opção 1 — arrastar e soltar (mais fácil)**
1. Acesse dash.cloudflare.com → Workers & Pages → Create → Pages → *Upload assets*.
2. Dê o nome `confereai` e arraste esta pasta (sem o README, opcional).
3. O site fica em `https://confereai.pages.dev`.

**Opção 2 — via GitHub (atualiza sozinho)**
1. Suba esta pasta para um repositório no GitHub.
2. Pages → *Connect to Git* → escolha o repositório.
3. Framework preset: *None*; Build command: vazio; Output directory: `/`.

Arquivos: `index.html`, `style.css`, `app.js`, `logo.svg`/`logo.png`, `_headers` (cabeçalhos de segurança).
